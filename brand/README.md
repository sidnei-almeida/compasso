# Kit de marca

| Arquivo | Uso |
|---|---|
| `mark.svg` | a marca sozinha (ícone, avatar, favicon) |
| `logo.svg` | marca + logotipo, para fundo escuro |
| `banner.svg` | cabeçalho do README e de redes (1280x360) |

## A marca

Um compasso de quatro tempos: três tempos em teal e o **tempo forte em âmbar**, mais alto que os
outros. É o sistema inteiro numa imagem: tudo cai no grid, e o golpe cai no tempo forte.

## Cores

| Nome | Hex | Uso |
|---|---|---|
| Tinta | `#0B0C10` | fundo |
| Superfície | `#15171C` | cartões, a marca |
| Osso | `#ECE7DF` | texto e o logotipo |
| Âmbar | `#E89B3C` → `#FFD28A` | o tempo forte, destaques, links |
| Teal | `#5FB0A6` | o grid, elementos secundários |
| Cinza | `#9AA3AF` | texto secundário |

## Tipografia

Inter, peso 600 para o logotipo (minúsculas, espaçamento -2), 400 para texto. Fallback: Helvetica,
Arial.

## Voz

Minúsculas no nome: **compasso**. Frases curtas. Nada de "revolucionário", "IA mágica"; o produto é
método e código. Tagline: *trilha de cinema por código, no compasso*.
